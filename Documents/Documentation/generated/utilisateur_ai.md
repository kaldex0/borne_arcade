# Documentation de la Borne d'Arcade

##  Documentation utilisateur

**Dmarrage**


- La borne d'arcade dmarre automatiquement au dmarrage du systme Raspberry Pi.
- Patientez jusqu' 10-15 secondes pour que le menu s'affiche.

**Navigation**

- **Joueur 1:** Utilisez le joystick pour naviguer dans le menu.  
- **Bouton A (J1):** Lancer un jeu.
- **Bouton Z (J1):** Quitter le menu (confirmation requise).


**Commandes par dfaut**

* **Joystick J1:** Flche Haut/Bas/Gauche/Droite.
* **Joystick J2:**  O / L / K / M.
* **Boutons J1:** R / T / Y / F / G / H.
* **Boutons J2:** A / Z / E / Q / S / D.


> **Note:** Le mapping des boutons peut varier selon le cblage de l'encodeur de la borne. Veuillez consulter le fichier `borne` pour les configurations spcifiques.

**Pendant un jeu**


- Les commandes spcifiques  chaque jeu sont affiches dans la zone "Description".
- Utilisez les boutons/le joystick indiqus pour jouer.
- Pour quitter un jeu, utilisez la touche ou la commande prvue par le jeu. 

**Exemple (StarDodger)**

* **Joystick J1:** Dplacement du joueur
* **Bouton A (J1):** Boost court

**Extinction**

- Aprs avoir quitt le menu, la borne s'teindra automatiquement aprs un compte  rebours de 30 secondes.
